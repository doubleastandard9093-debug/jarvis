# Jarvis

Jarvis is a day planner you can talk to. It plans your day, keeps your tasks, and works offline.
This repository holds only the built web app (a home-screen app for iPhone). The source code is private.
Updates are published here automatically after the private repo's tests pass.

**Open it:** https://doubleastandard9093-debug.github.io/jarvis/

## Add it to your iPhone home screen

1. Open the link above in **Safari** (not Chrome).
2. Tap **Share**, then **Add to Home Screen**, then **Add**.
3. Open Jarvis from the new icon. It opens full screen, and after the first visit it works with no signal.

Data you enter in Safari doesn't carry over to the home-screen app (iPhone keeps them separate), so use the icon.
Use **Settings > Export backup** now and then, because iPhone can clear website data.

## Bring your own free Gemini key

Planning works without a key, using the built-in offline planner. For chat replies from Gemini,
paste your own free key from Google AI Studio in **Settings**. The key stays on your device only.
It is never part of these files and never leaves your phone except in requests to Google.
**Clear key** removes it.

## What the web version can't do

Voice input, the on-phone AI model, and reminders while the app is closed only work in the native app.
